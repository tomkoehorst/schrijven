# Schrijfkamer

Een rustige schrijfapp in de browser, met een indeling zoals in Ulysses: bibliotheek, lijst met teksten en een schone editor met Markdown-opmaak.

## Gebruiken

- **Online (met synchronisatie):** via de claude.ai-link. Je teksten worden daar tussen je telefoon en computer gesynchroniseerd.
- **GitHub Pages:** open `https://tomkoehorst.github.io/schrijven/`. Je teksten worden daar alleen in de browser van dat apparaat bewaard (localStorage).

## Functies

- Inbox, alle teksten, laatste 7 dagen, favorieten, groepen met kleur, prullenbak
- Opmaak met `# kop`, `**vet**`, `*cursief*`, `==markeren==`, `> citaat`, lijsten, links en `++notities++`
- Schrijfdoel per tekst met voortgangsring, statistieken en een inhoudsopgave
- Voorbeeldweergave, focusmodus, typemachinemodus en alinea uitlichten
- Licht/donker thema, drie lettertypes, instelbare grootte en regelbreedte
- Exporteren als Markdown, platte tekst of HTML

## GitHub Pages aanzetten

Settings → Pages → *Deploy from a branch* → branch `main`, map `/ (root)` → Save.
